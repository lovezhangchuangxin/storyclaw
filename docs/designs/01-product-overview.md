# 01 — 产品概述

## 产品定位

StoryClaw 是一个 Agent 驱动的中短篇小说创作与阅读 Web 应用（Web + PWA）。

**核心差异化：**
- **中短篇小说**，而非长篇小说。目标篇幅：50,000 字以下
- **Agent 驱动创作**，用户描述需求，Agent 理解意图、设计大纲、规划章节、自动写作
- **用户不可手动编辑小说**，一切内容由 Agent 生成，用户只阅读和反馈
- **一流的阅读体验**是核心，而非编辑器体验

**与现有工具的差异：**

| 维度 | 传统 AI 写作工具 | StoryClaw |
|------|-----------------|-----------|
| 篇幅 | 长篇 | 中短篇（≤50,000 字） |
| 交互 | 复杂表单 + 手动编辑器 | 自然语言 + Agent |
| 重心 | 编辑体验 | 阅读体验 |
| 用户角色 | 作者 | 读者 + 反馈者 |

## 用户旅程

```
用户打开应用
  → 描述故事创意（一句话即可）
    → Agent 设计大纲、角色、世界观
      → 用户审阅，提出反馈
        → Agent 调整并开始创作章节
          → 用户阅读，实时反馈
            → Agent 根据反馈调整后续章节
              → 故事完成，用户反复阅读
```

**核心循环：阅读 → 反馈 → Agent 重写/续写 → 阅读**

## 功能范围

### MVP（Phase 1）
- 纯前端单页应用（Vite + Vue3 + PWA + Tailwind + shadcn-vue）
- 阅读器：字体、字号、行距（颜色跟随应用主题）
- 3 套应用主题（浅色/深色/护眼），作用于全 UI
- 单 Agent + 基础 Tools（生成大纲、生成章节、修改文风）
- IndexedDB 本地存储
- 模型配置页（OpenAI 兼容接口）
- PC 和移动端适配

### Phase 2 — Agent 增强
- Agent Loop 迁移到 Web Worker
- Prompt Caching + Cache-aware Context Compaction
- 更多 Tools（重写章节、角色调整、情节分支等）
- 更多应用主题
- PWA 离线阅读完善

### Phase 3 — 后端 + 多 Agent
- Rust + Axum 后端（注册/登录/同步/LLM 代理）
- 多设备数据同步
- 管理后台（管理员查看所有数据）
- Skills / Multi-Agent / Hooks 系统

## 核心约束

- 一本小说 = 一个会话（不可多会话并行）
- 用户可清空当前会话重来，不保留历史会话
- 后端连接是可选的，纯前端即可正常使用
- 前端调模型（直连），连接后端后可选择由后端代理调用
