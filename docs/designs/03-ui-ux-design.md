# 03 — UI/UX 设计

## 设计原则

- **阅读优先**：故事详情页默认展示阅读器，Agent 对话通过切换进入
- **移动端可操作**：所有核心功能在手机上可单手完成
- **沉浸式阅读**：阅读时隐藏所有界面 chrome，点击底部区域唤出控制栏
- **渐进式交互**：复杂功能分层展示，不强塞给用户

## 信息架构

```
底部 Tab Bar
├── 书架     — 所有小说的卡片列表
├── 创建     — 开始新故事的入口
└── 我的     — 设置、模型配置、后端连接

故事详情页（从书架进入）
├── 阅读模式  — 沉浸式阅读器（默认）
└── Agent 模式 — 创作/反馈对话（右上角切换按钮）
```

**导航规则：**
- 书架 / 创建 / 我的 通过底部 Tab Bar 切换
- 从书架点击小说卡片 → 进入故事详情页（覆盖 Tab Bar，全屏）
- 故事详情页右上角有切换按钮，在"阅读"和"Agent"之间切换
- 故事详情页左上角返回按钮，回到书架
- 设置页（模型配置、后端连接）从"我的"Tab 进入
- 管理员后台在"我的"页面底部，仅管理员可见

```
│  比理智更重要。                  │
│                                  │
│  ...                             │
│                                  │
│  （上滑继续阅读）                 │
└──────────────────────────────────┘
```

**控制栏（点击底部 60px 区域唤出）：**

```
┌──────────────────────────────────┐
│  ← 目录  第十二章 / 共24章       │
│  ─────────────────────────────── │
│  字体: 思源宋体 ▼  字号: 18 ▼   │
│  行距: 1.8 ▼       颜色: #333 ▼ │
│  背景: 米白 ▼       主题: 静谧 ▼ │
│  ─────────────────────────────── │
│  [给本章反馈]  [切换章节]       │
└──────────────────────────────────┘
```

**阅读设置（从控制栏进入全屏设置面板）：**
- 字体选择（系统可用字体列表）
  - 衬线：思源宋体、Noto Serif、Georgia
  - 无衬线：思源黑体、Inter、系统默认
- 字号：12px – 24px，默认 18px
- 行高：1.4 – 2.4，默认 1.8
- 段间距：0 – 2em
- 文字颜色：预设色板 + 自定义
- 阅读背景：纯色 + 纹理可选

**翻页/滚动模式：**
- 上下滚动（默认，适合移动端）
- 左右翻页（适合 PC 端宽屏）
- 自动滚动（可调速）

**交互规则：**
- 单击底部 60px 区域 → 唤出控制栏
- 单击正文区域 → 不触发（保留给文本选择和滚动）
- 长按文本 → 文本选择
- 双击 → 无操作

**章节完成后过渡：**
当 Agent 完成一个新章节后，用户在 Agent 模式下看到通知卡片"第 X 章已生成"，
点击卡片直接跳转到阅读模式查看该章节。

- 用户可通过输入框提供反馈，或在控制栏使用"给本章反馈"

## 通用状态设计

所有数据加载页面遵循统一的状态模式：

| 状态 | 表现 |
|------|------|
| **加载中** | 骨架屏占位（卡片/文本行），不显示空白页 |
| **空数据** | 插画 + 引导文案 + 行动按钮 |
| **错误** | Toast 提示错误信息 + 重试按钮 |
| **离线** | 顶部横幅提示"当前离线"，阅读器正常，Agent 禁用 |

Agent 生成过程中的状态：
| 状态 | 表现 |
|------|------|
| **思考中** | 输入框上方显示"Agent 正在思考..."脉冲动画 |
| **工具调用中** | 显示工具名称和参数摘要（如"正在修改大纲..."） |
| **流式生成中** | 逐 token 渲染内容，光标闪烁 |
| **生成完成** | 光标消失，显示时间戳 |
| **生成中断** | 已生成内容保留，显示"已中断"标记 |
| **生成错误** | 错误消息 + "重试"按钮 |

## 无障碍设计

- 所有阅读主题的背景/文字对比度 ≥ 4.5:1（WCAG AA）
- 阅读器支持键盘导航：↑↓ 滚动、←→ 翻页、Esc 退出全屏
- Agent 对话支持屏幕阅读器：消息角色（user/assistant）通过 aria-label 标注
- 焦点管理：模态框打开时焦点锁定在框内，关闭后恢复
- 表单控件关联 label，错误提示通过 aria-describedby 关联

---

## 移动端适配

- 阅读器：全屏沉浸，底部 60px 为控制栏触发热区
- 字体默认 14-16px，适应小屏
- Agent 模式：底部输入框固定，键盘弹起时视图自动上移
- 书架：单列卡片布局
- 底部 Tab Bar 固定

## PC 端适配

- 阅读器：最大宽度 680px 居中，两侧留白
- Agent 模式：分栏布局，左侧对话区（60%），右侧故事状态面板（40%）
- 键盘快捷键：↑↓ 滚动、←→ 翻页、Esc 返回书架、Ctrl+K 快速命令面板
